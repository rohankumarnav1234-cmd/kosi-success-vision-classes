KOSI SUCCESS VISION CLASSES — ऐप पैकेज (शुरुआती संस्करण)

इस पैकेज में क्या है:
- index.html: मोबाइल और लैपटॉप के लिए पूरा चलने वाला ऐप
- शिक्षक सेक्शन: इसी ब्राउज़र में डेमो पासवर्ड सेट करना, सूचना बदलना, नोट्स जोड़ना
- 5 सवालों का MCQ टेस्ट
- स्टडी मटेरियल, टाइमटेबल, कक्षा 9/10/11 चयन

लैपटॉप पर तुरंत चलाएँ:
1. ZIP को Extract All करें।
2. index.html पर डबल-क्लिक करें।
3. Chrome में ऐप खुल जाएगा।
4. शिक्षक सेक्शन खोलें → “पासवर्ड बनाएँ / बदलें” → पासवर्ड दो बार डालें → सेट करें।
5. शिक्षक सेक्शन में वापस जाकर पासवर्ड से खोलें; सूचना/नोट्स जोड़ें।

महत्वपूर्ण सुरक्षा सीमा:
यह अभी single-device demo है। पासवर्ड browser local storage में रहता है, इसलिए यह असली सुरक्षित लॉगिन नहीं है। सूचना और नोट्स केवल उसी ब्राउज़र/डिवाइस में सेव होते हैं। दूसरे विद्यार्थियों के फोन में अपने आप नहीं पहुँचेंगे। वास्तविक साझा लॉगिन/डेटा के लिए backend/database और सुरक्षित authentication जोड़ना होगा। कोई संवेदनशील पासवर्ड इस डेमो में न रखें।

मोबाइल और लैपटॉप दोनों में:
- फाइल को Chrome में खोलकर इस्तेमाल करें।
- स्थायी install / offline सुविधा के लिए वेबसाइट को HTTPS पर publish करना होगा।

APK:
इस ZIP में APK फ़ाइल शामिल नहीं है। ऑनलाइन HTTPS साइट प्रकाशित करने के बाद https://www.pwabuilder.com पर URL डालकर Android package बनाने की प्रक्रिया शुरू की जा सकती है। पैकेज बनाने से पहले साइट और permissions जाँचें; टूल की मौजूदा प्रक्रिया बदल सकती है।
